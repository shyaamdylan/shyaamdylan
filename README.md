## How I work

I build with AI coding tools and I'm open about that. My part is the product: finding the problem, deciding what to build and what to leave out, testing with users, and getting it released. I learned React Native to build the first version of Astra. I wrote Python and Java at school and at Warwick, where my strongest marks were in the computing modules.
